사용자 요청: "진행해". 바로 앞 대화의 미완료 항목은 테스트 배지의 실제 통과 상태 확인과 CI 자동 갱신이었다. 현재 요청은 "현재 저장소 상태를 검증한 뒤, 현재 정책과 승인 범위 안에서 최신 유효 의도를 완료"하는 것이다.

목표는 타 사용자가 공개 저장소에서 실제 테스트 상태를 확인하고 각자 구독한 계정으로 설치·사용할 수 있게 하는 것이다. 정적인 테스트 개수 대신 GitHub Actions 실행 결과를 표시한다. 실패 테스트를 삭제하거나 약화하지 않으며 실제 계정, 운영 프록시, npm 배포는 이 작업에 포함하지 않는다.
